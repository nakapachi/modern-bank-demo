# Security Policy / セキュリティポリシー

## Reporting a Vulnerability / 脆弱性の報告

脆弱性を発見した場合は、公開Issueへ詳細を書き込まず、GitHubのPrivate vulnerability reportingから報告してください。実在する金融機関や実際の顧客データを使った検証は行わないでください。

If you discover a vulnerability, do not disclose its details in a public issue. Please use GitHub Private vulnerability reporting. Do not test with real financial institutions, real funds, or real customer data.

## Supported Version / サポート対象

最新のGitHub Releaseのみを対象とします。このプロジェクトは学習用デモであり、本番の金融サービスとしての利用はサポートしていません。

Only the latest GitHub Release is supported. This project is an educational demo and is not supported for production banking use.
